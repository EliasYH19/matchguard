About MatchGuard

A Cloud Computing final project - anti-cheat verification as a service for grassroots and mid-size gaming tournaments.

Why this idea

Most anti-cheat tooling (Vanguard, EAC, BattlEye) is built into the game client and out of reach for community-run tournaments using games that don't ship one, or LAN events running console/emulator brackets. MatchGuard plugs that gap: organizers buy a package, players upload a snapshot, and the organizer gets a verdict and paper trail without writing a line of code.

Architecture

Two independent Flask microservices behind a static frontend, one serverless function, Azure Blob Storage, Docker + Kubernetes.

  • frontend - static HTML/CSS/JS, served by nginx
  • tournament-service - tournaments, packages, purchases, registrations (REST API)
  • scan-service - evidence upload, hashing, signature scan, flagged feed (REST API)
  • notify-function - Azure Function, generates verification certificates (serverless)

Try the scan yourself

Two tiny sample log files are included in the repo under docs/sample-uploads/ so you (or your grader) can test both verdict paths without needing a real cheat tool:

  • clean-system-log.txt — comes back CLEAR
  • suspicious-system-log.txt — comes back FLAGGED (contains "aimbot" and "cheatengine" strings)

Register a player on any tournament, then use these files in the "Submit an anti-cheat scan" form.
